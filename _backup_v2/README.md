# ERSL_V2 Pre-Update Backup Snapshot

Created before applying the V3 redesign and CMS updates.
Note: All files use `.bak` extension so TypeScript (`tsconfig.json`) and Vite do not compile duplicate source files.

To restore any file, copy its `.bak` file back over the original path (removing `.bak`).

Included in this backup folder:
- `src/types.ts.bak`
- `src/data/news.ts.bak`
- `src/components/UAHeader.tsx.bak`
- `src/components/NewsModal.tsx.bak`
- `src/components/AdminDashboard.tsx.bak`
- `src/components/BoxFolders.tsx.bak`
- Plus git history in `.git/` (if tracked in git) preserves the complete previous commit state.
